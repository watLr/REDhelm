# Security

Please don't report a security problem in a public issue.

**[Report it privately](https://github.com/watLr/redhelm/security/advisories/new)** instead. You need a GitHub account, and only the maintainer and anyone they invite to the report can see it.

Tell us what could go wrong, how to make it happen, and your REDhelm and Claude Code versions (`/redhelm feedback` fills in a link with both). Leave out real passwords, keys and other people's data: a made-up example is enough.

Fixes ship in a new release, so only the latest REDhelm is supported. Replies are best effort.

A problem in Claude Code itself, rather than in REDhelm, is for Anthropic.
